# Landing Page de Joyería

Página web con temática de joyería desarrollada como práctica de HTML y CSS.

## Descripción

Este proyecto consiste en una landing page para una joyería ficticia llamada "The Wings of Elegance". Incluye una sección de inicio, catálogo de productos, artículos, sucursales y contacto.

## Tecnologías utilizadas

- HTML
- CSS

## Objetivo del proyecto

Practicar la estructura de una página web, el diseño visual, la organización de secciones, el uso de imágenes y la creación de tarjetas de productos.

## Características

- Menú de navegación.
- Sección principal con imagen de fondo.
- Presentación de productos populares.
- Catálogo de joyería.
- Diseño visual enfocado en una marca elegante.

## Nota

Este proyecto fue realizado como práctica inicial, por lo que está optimizado principalmente para una resolución de escritorio y puede no contar con diseño responsive completo.

## Mejoras futuras

- Adaptar el diseño a celulares y tablets.
- Mejorar la responsividad.
- Optimizar las imágenes.
- Agregar más interactividad con JavaScript.
